# Grupo San Guillermo — sitio público

Sitio institucional de **Grupo San Guillermo S.A.**, operador de la estación AXION energy,
el punto AXION energy Agro y la tienda Spot en San Guillermo, Santa Fe.

Proyecto independiente: HTML + CSS + JS sin dependencias ni build.
Para verlo, abrí `index.html` en el navegador o serví la carpeta con cualquier servidor estático.

## Concepto
"Un techo sostenido por cuatro entidades": la estación es de las cooperativas y la mutual
del pueblo. El techo de la estación del hero se apoya en cuatro columnas, una por entidad socia.
